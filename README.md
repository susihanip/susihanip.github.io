## 성적 입력 → 판정 사유

`내 성적 넣고 대학 추리기` 카드에서 두 가지를 입력할 수 있습니다.

1. **내신 등급** (1.0~9.0) + 비교할 전형(학생부교과 / 학생부종합)
   → 2026학년도 70% 컷의 `p20`·`중위`·`최고` 컷과 내 등급을 등급 차이로 비교해 **안정/적정/소신/어려움** 배지를 매깁니다.
2. **수능·모의고사 등급 (선택)**
   - `과목별` : 국어 · 수학 · 영어 · 탐구1 · 탐구2 각 1~9등급
   - `등급합` : 2합 / 3합 중 고르고 합계 등급 입력
   → 입력하면 각 대학 카드에 **수능최저 충족/미충족**까지 판정합니다. 비워 두면 내신만으로 판정합니다.

카드마다 아래 세 줄이 붙습니다.

| 줄 | 내용 |
| --- | --- |
| `내신` | `내 2.80 vs 중위 컷 1.88 → 0.92등급 부족 · 최고 컷 2.31 이내(0.49등급 여유)`처럼 컷과의 등급 차이 |
| `수능최저` | `내 3합 7 (국 3·영 2·탐 2) → 3개 영역 합 7(학교추천) 기준 충족 · 한국사 4등급` / `미적용 전형 있음` / `요강 확인` |
| 판정 문장 | 내신이 부족한지, 수능최저가 부족한지, 전형이 없는지를 구분해 설명하고 다른 전형/대안을 안내 |

계산 규칙

- 탐구는 입력한 탐구1·탐구2 중 **좋은 등급 1과목**을 한 영역으로 셉니다(대부분 대학 기준).
- `N개 영역 합 M`은 국·수·영·탐 중 **가장 유리한 N개 영역**의 합으로 비교합니다.
- 기준에 `수학 필수`, `국·수 중 1개 포함`, `한국사 N등급` 조건이 있으면 함께 표시합니다.
- 미적용 예외(간호·의예 등 일부 모집단위만 적용)는 `narrow`로 표시해, 일반 모집단위에 불리하게 적용하지 않습니다.
- 영어 감점·탐구 반영 과목 수·제2외국어 대체는 반영하지 못하므로 결과는 **참고용**입니다.

## 데이터 필드

### `data/universities.json`

| 필드 | 설명 |
| --- | --- |
| `name` / `campus` | 대학명 · 캠퍼스 |
| `types` | 수시 전형 (`학생부교과` · `학생부종합` · `논술` · `실기`) — 카드 태그이자 필터 기준 |
| `quota` | 2027학년도 수시 모집인원 (요강 기준) |
| `schedule` | 2026년 9월 원서접수 기간 (대학별 마감 시각 상이) |
| `summary` | 주요 전형 · 전형방법 · 수능 최저 요약 |
| `noticeUrl` / `pdfUrl` | 입학처 공지·모집요강 원문 페이지 / 요강 PDF |
| `shortsUrl` | 1분 요약 쇼츠 링크 (`""`이면 ‘준비 중’ 버튼) |
| `region` | `서울` · `수도권` · `지방` |

### `data/cutoffs.json`

`universities.<id>.{gyogwa|jonghap}` = `{min, max, median, p20, p80, n}`,
`suneung_choejeo`(대학 단위 적용 여부), `note` / `gyogwa_note` / `jonghap_note`(미공개·미운영 사유).
출처: 대입정보포털 어디가 2026학년도 전형 결과(최종등록자 70% 컷). 재현 스크립트는 `work/admission-cutoffs/`.

### `data/suneung.json`

```json
"korea": {
  "교과": {"criteria":[{"kind":"sum","count":3,"limit":7,"label":"학교추천","flags":{"hanguksa":4}}],
           "none":[], "applied":["학교추천"]},
  "종합": {"criteria":[{"kind":"sum","count":3,"limit":8,"label":"학업우수","flags":{"hanguksa":4}}],
           "none":["계열적합","고른기회","다문화","재직자","사이버국방"], "applied":["학업우수"]}
}
```

- `criteria` : `kind`(`sum` = N개 영역 합, `topN` = N등급 M개 이상), `count`, `limit`, `label`(전형·계열), `flags`, `narrow`(일부 모집단위만)
- `none` : 수능최저 미적용 전형 이름
- `applied` : 수능최저를 적용하지만 수치가 원문에 없어 요강 확인이 필요한 전형
- 출처: 대입정보포털 어디가 **2027학년도 대학별 전형평가기준 「전형별 주요사항」** + `universities.json` 요강 요약.
  수집·구조화 스크립트는 `work/susihanip-suneung/`(`build2.py` → `build3.py`).
