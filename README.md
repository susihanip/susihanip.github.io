# 수시한입 · 대학별 수시모집요강 모음

유튜브 **수시한입(@susihanip)** 채널용 2027학년도 대학별 수시모집요강 모음 사이트입니다.
정시한입 사이트(`work/jeongsihanip-repo/`)의 디자인·레이아웃·반응형 카드 UI를 그대로 이어받아 만들었고,
포인트 컬러만 **골드/옐로우(FACC15 · FBBF24 · F59E0B)** 로 바꿨습니다.

## 구조

```
index.html            페이지 (헤더 · 히어로 · 검색/필터 · 카드 목록 · 안내)
style.css             다크 네이비 + 골드 테마
app.js                검색 · 전형 필터 · 카드 렌더링
data/universities.json  대학 23곳 데이터 (요강 링크 · 모집인원 · 일정 · 전형 · 수능최저 요약)
```

## 데이터 필드

| 필드 | 설명 |
| --- | --- |
| `name` / `campus` | 대학명 · 캠퍼스 |
| `types` | 그 대학이 수시에서 운영하는 전형 (`학생부교과` · `학생부종합` · `논술`) — 카드 우측 태그이자 필터 기준 |
| `quota` | 2027학년도 수시 모집인원 (요강 기준) |
| `schedule` | 2026년 9월 원서접수 기간 (대학별 마감 시각 상이) |
| `summary` | 주요 전형 · 전형방법 · 수능 최저 요약 |
| `noticeUrl` | 입학처 공지·모집요강 원문 페이지 |
| `pdfUrl` | 입학처가 배포하는 2027학년도 수시모집요강 PDF |
| `shortsUrl` | 1분 요약 쇼츠 링크 (`""`이면 ‘1분 요약 쇼츠 준비 중’ 버튼 표시) |

서울대 · 연세대 · 고려대 · 서강대 · 성균관대 · 한양대 · 건국대 · KAIST · POSTECH · 중앙대 · 경희대 ·
한국외국어대 · 서울시립대 · 이화여대 · 동국대 · 홍익대 · 숙명여대 · 국민대 · 숭실대 · 세종대 ·
단국대 · 아주대 · 인하대

> 모든 `noticeUrl` · `pdfUrl`은 각 대학 입학처가 실제로 배포 중인 2027학년도 수시모집요강 문서로 확인해 채웠습니다.
> `shortsUrl`은 영상이 올라오기 전까지 비워 두었습니다.

## 로컬 실행

```bash
cd work/susihanip-web
python3 -m http.server 8765
# http://localhost:8765/
```

`fetch("data/universities.json")`을 쓰기 때문에 `index.html`을 파일로 직접 열지 말고 HTTP 서버로 열어야 합니다.
